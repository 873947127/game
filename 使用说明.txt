【怎么开始玩】
1. 双击打开本文件夹里的「index.html」文件
   （会默认用浏览器打开，不用联网，不用装任何东西）
2. 在开局界面点「🎮 单机对战」，然后选择：
   玩家人数（2~6人）、每个座位是「真人」还是「电脑」
3. 点「开始游戏」就能玩了
   （想和朋友玩，就点「🌐 联机对战」，从下面的两种方式里选）

【怎么和朋友联机玩】（在主页点「🌐 联机对战」后选一种）
● 🌐 服务器版（最稳定）：需要一个云端地址，见「部署说明.txt」
   - 部署好后，所有人打开同一个网址即可，能跨网络玩
● 🕸 直连版（无需部署，完全免费）：一个玩家当主机，朋友直接连他
   - 走下面的【线上直连玩】步骤

【怎么和朋友线上直连玩】（无需服务器，完全免费）
1. 把这个文件夹整个发给朋友（或压缩成zip发过去），大家都打开里面的「p2p.html」
2. 一个人点「🏠 我当主机」→ 设总人数 → 点「生成一个座位连接码」
3. 把连接码复制发给一位朋友
4. 朋友点「👋 我加入朋友」→ 粘贴连接码 → 点连接 → 得到「回答码」
5. 朋友把回答码发回 → 主机粘到对应座位框点「连接」→ 连接成功
6. 每位朋友各连一次（4人局=3位朋友=3个码），人齐了主机点「开始游戏」

小提示：直连是浏览器之间直接连，公司/校园等严格网络可能连不上；
主机不能关页面，否则游戏断开。

【怎么玩】
● 每轮开始会翻开一张牌，作为本轮的【熄灯时间】
● 轮到你时：摸1张牌 → 扣着打出几张牌（假装自己是早睡）
● 你的下家可以选择「质疑」或「相信你」
   - 你真在早睡 → 下家质疑失败，他要收牌 + 摸等量牌
   - 你其实在熬夜 → 下家质疑成功，你拿回牌 + 摸等量牌
● 手牌先清到 0 张的人获胜！手牌超过 20 张会被直接淘汰
● 抽牌堆不够时，弃牌堆会自动洗回去，不会卡住

【什么叫早睡 / 熬夜】
● 早睡 = 打出的牌【全是同一种时间】且【不晚于熄灯时间】
  （比如熄灯时间是晚上10点，你打1张晚上10点、或3张晚上9点，都是早睡）
● 熬夜 = 打出的牌【混了≥2种时间】，或【有牌晚于熄灯时间】
● 怎么骗过别人，让别人以为你在早睡？这就是唬牌的乐趣！

【技能卡】共18张，每种时间点3张
  晚9：  回笼觉 / 梦中桃花源 / 褪黑素软糖
  晚10： 清醒梦 / 噩梦 / 预知梦
  晚11： 抓到你熬夜了 / 该补觉了 / 观星
  晚12： 蒸汽眼罩 / 瞌睡虫 / 午夜凶铃
  凌晨1：咖啡 / 热牛奶 / 提前熄灯
  凌晨2：延迟熄灯 / 宵禁命令 / 狂欢派对

【怎么查看技能介绍】
● 把鼠标悬停到手牌或场上的技能牌上，会弹出完整介绍
● 游戏里点右上角「📜 规则」按钮，可以看到全部技能的原句说明

【常见问题】
● 点了没反应？→ 先看看最上方提示栏在说什么，现在该谁操作
● 想听背景音乐？→ 点顶栏的「🔇 音乐」开关（开局会自动播放），旁边的滑杆可调音量
● 没有音效？→ 游戏里的按钮、出牌、摸牌、质疑翻牌等都有音效，音量跟着顶栏滑杆走
● 想换人数或座位？→ 点右上角「↻ 重新开局」
● 全屏更舒服？→ 按 F11

【小提示】
● 真人也坐在同一台电脑上，轮到谁就把鼠标交给谁
● 游戏里「预知梦」「观星」会弹窗展示，看完点确认就行
